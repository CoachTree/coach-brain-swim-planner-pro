# Frontend

React 19 app for Coach Brain Swim Planner Pro.

## Scripts

```bash
npm install
npm start
npm run build
```

`npm start` runs the development app at `http://localhost:3000`.

`npm run build` creates the production static site in `build/`.

## Deployment

Deploy the `build/` directory to any static host. The app is local-first and
does not require a backend for session generation, sharing, PDF export, coach
library storage, or season planning.
